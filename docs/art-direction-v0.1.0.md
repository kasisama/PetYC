# 自然遗迹调查 · 美术生成大纲 v0.1.0

给外部绘图工具用。禁止出现伊布、呱呱、皮卡丘、宝可梦、第三方卡通 IP 脸型。做成「野外调查队图鉴」而不是战斗卡牌。

## 1. 总风格

参考《洛克王国》页游官方图鉴立绘：薄暖色线、气刷体积感、完成度像能进商城预览。不要贴纸描边，不要 3D 手办，不要水彩纸纹。画面上不要任何文字和水印。

- 媒介：2012 前后腾讯页游官方 2D 原画，细暖棕线，三档气刷明暗，淡椭圆落地影。
- 体感：是设计过的小动物，有耳内、吻、胸纹、标志物；不是果蔬 Logo，也不是厚黑边表情包。
- 眼睛：彩色虹膜 + 瞳孔 + 两个高光。
- 背景：浅灰棚拍纯底。地图/区域才画场景。
- 剪影：3 米外仍能认出谱系。同一谱系从头到尾共用身体结构，只升级体量和饰物。
- 禁止：文字、水印、UI 框、真人、洛克王国现有宠物（喵喵、火花、水蓝蓝、迪莫等）以及任何第三方 IP。

统一提示词尾缀（每张都加）：

```
refined official 2D encyclopedia illustration, Tencent 2012 Flash MMORPG pet key art, thin warm-brown lineart, airbrushed three-value shading, faint oval ground shadow, light gray studio background, no text, no watermark, no 3D render, no clipart, no copyrighted characters
```

## 2. 文件规格

放到 `config/defaults/assets/` 下，文件名用英文键，不要中文文件名。

| 类型 | 尺寸 | 格式 | 目录 |
| --- | --- | --- | --- |
| 宠物立绘 `Image` | 1024×1024 | PNG，透明或浅米色底 | `宠物图片/{key}.png` |
| 领养图 `AdoptImage` | 1024×1024 | PNG | `核心图片/领养_{key}.png` |
| 货币/物品图标 | 512×512 | PNG | `物品图片/{key}.png` |
| 地图封面 | 1920×1080 | PNG | `地图图片/{map_key}.png` |
| 区域图 | 1280×720 | PNG | `地图图片/{zone_key}.png` |
| 装备图标 | 512×512 | PNG | `装备图片/{key}.png` |
| 互动/签到 | 1024×1024 | JPG/PNG | 沿用现有 `互动图片/` `核心图片/` |

第一批只做 **P0 + P1**。P2、P3 空着也能开服。

生成同一谱系后续形态时，把基础形态图当作参考图，不要重新随机一种动物。

阶段升级只加体量和饰物，不换物种：

- **base**：幼体，头身比大约 1:1.2，表情清楚。
- **evolved**：青年，饰物出现（叶冠 / 苔纹 / 焰纹 / 岩脊 / 风环）。
- **awaken_a**：曦光路线，更亮、更仪式感。
- **awaken_b**：月影路线，更沉、更隐蔽。两条觉醒必须一眼能看成同一只兽的两条路，不能变成两个无关物种。

## 7. P3 可后补

- 24 只普通生态生物、6 精英、3 首领（首领要更纪念碑，但仍是生态生物，不是机甲）。
- 30 件装备：武器 / 防具 / 秘宝三槽，稀有度越高材质越从藤木走向盐晶和雾木，不要现代枪。
- 互动缺图：回击成功/失败、开始/完成学习、开始/完成锻炼、抽奖、抛竿（配置有路径但目录里可能缺文件）。

首领三张如果做，单独加大体量：

- 逐日原角王：草原巨角兽，角像日轮切面。
- 深潮观测体：半生物半古代观测装置，仍要像潮池生物。
- 千年雾冠主：树冠与兽身融在一起，不是人脸树妖。

## 8. 生成顺序（建议你按这个点）

1. 先出 5 只 **base**，确认谱系能分开，再复制参考图做进化和觉醒。
2. 5 张领养图（同一只兽换构图）。
3. 3 张地图封面。
4. 3 枚货币 + 进化核 5 枚 + 便当/绷带。
5. 其余物品和区域。
6. 最后怪和装备。

同一谱系务必「图生图 / 参考图」，不要每张都纯文生图，否则 20 只会散成 20 个物种。

## 9. 生成后怎么交给游戏

文件按第 2 节命名放进 `config/defaults/assets/`。告诉我目录已经放好，我再把路径写进：

- 宠物的 `Image` / `AdoptImage`
- 物品/货币的 `image`
- 地图/区域的 `image`
- 必要时 `images` 表里的互动图

在此之前空字段可以开服，只是聊天里没有立绘。
