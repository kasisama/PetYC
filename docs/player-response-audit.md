# 玩家回复全量体验审计

更新日期：2026-08-24

## 审计规则

- `高潮`：完整标题、宠物/场景反应、真实变化、现有配图和下一步。
- `信息`：层次清晰，有简短世界观包装和可执行引导。
- `友好`：输入或条件问题只说明原因、正确格式和补救办法。
- `克制`：隐私、删除、二次确认及技术故障不使用庆祝语气。
- 群与频道回复必须指向操作者；OneBot 使用真实 CQ 艾特，QQ 频道使用原生艾特，QQ 官方群使用引用回复与 `@昵称`。
- 所有技术错误只进入日志；玩家侧不得出现 SQL、HTTP、文件路径、UUID、OpenID 或原始错误。

分支缩写：`S` 成功、`L` 列表/空状态、`V` 输入错误、`B` 业务条件不足、`T` 技术故障、`N` 主动通知。

## 发布门禁

1. 每个启用命令经统一路由返回非空 `MessageKey`。
2. 群聊回复始终存在平台可识别的目标玩家标记或引用关系。
3. 本地图片必须位于图片根目录且真实存在；无图时正文仍完整。
4. 成功文案中的奖励、消耗、余额和状态变化必须来自领域服务结果。
5. 新增玩家回复必须经过统一 `text`/`messageText` 构造入口，禁止处理器直接创建匿名 `OutboundMessage{Text: ...}`。
