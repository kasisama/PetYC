# QQ-Pet v0.0.1 冒险、远征、图鉴与活动配置说明

## 核心结论

地图、区域、怪物、难度、掉落、首领刷新、装备和配方全部是 SQL 配置，不再由“林间、遗迹、深层”三个固定档位决定。旧远征记录只用于兼容已经出发但尚未领取的任务；新玩家流程从大地图开始。

永久冒险内容与限时活动是两条不同的数据链：

- 冒险世界负责地图、探索度、战斗、永久图鉴、远征解锁、首领和装备产出。
- 活动负责一段时间内的进度来源、群内故事投票和里程碑奖励。
- 活动可以选择全部区域远征或指定区域远征作为进度来源，但不会创建地图，也不会重置永久图鉴。

## 玩家完整流程

1. 玩家发送“地图”，查看已开放的大地图、区域、推荐冒险等级、前置区域、探索度和远征状态。
2. 玩家发送“探索 区域名”。系统检查区域前置、宠物状态、饱食和准备度，然后按后台权重抽取怪物、地标或安全事件。
3. 遇到怪物后进入持久化回合战斗。玩家可普攻、防御、使用已掌握技能或撤退；消息重试使用行动键防止重复结算。
4. 怪物会按照后台配置的属性、区域难度和技能权重行动。胜利后结算固定掉落池、随机掉落池、冒险经验、目标进度和图鉴发现。
5. 区域探索度按目标权重计算，不按进入次数硬加。进入、击败普通怪、击败精英、发现地标和参与击败首领都可以是独立目标。
6. 完成区域指定的“远征解锁目标”后，该区域才允许挂机远征。未挑战过的区域不能直接派遣。
7. 区域远征保存出发时的地图、区域、奖励、战力、评级和活动来源快照；到期后领取，避免运营中途改配置影响已出发任务。
8. 玩家使用地图掉落的材料、低阶装备和蓝图碎片强化宠物。蓝图碎片累计到阈值后永久解锁配方，再消耗材料和货币制造高阶装备。
9. 装备分为武器、防具和“秘宝”。装备具有固定基础属性与后台词条池生成的随机词条；v0.0.1 不允许玩家交易装备。
10. 群或频道中的玩家可在首领出现窗口内挑战共享生命值的限时首领。奖励由最低参与贡献、基础奖励池和个人贡献档位共同决定，且只能领取一次。

## 后台配置关系

### 地图与区域

- 大地图：名称、区域主题、封面、推荐等级、排序和启用状态。
- 区域：所属地图、推荐等级、千分比难度、探索消耗、图片和远征解锁目标。
- 区域前置：要求先完成哪些区域，用于组成非循环的探索路线。

### 遭遇、战斗与探索度

- 遭遇表：区域内可能出现的怪物、地标或安全事件及权重。
- 怪物表：生命、攻击、防御、智慧、冒险经验、AI 标识及固定/随机掉落池。
- 怪物技能表：将技能按权重分配给怪物；未抽中技能时使用普通攻击。
- 探索目标：定义目标类型、目标键、所需次数、探索度权重及完成后推进的图鉴条目。

### 掉落、装备与合成

- 掉落池控制抽取次数和是否允许重复。
- 掉落内容支持物品、货币、装备和蓝图碎片，并可标记必掉或首通限定。
- 装备模板控制槽位、稀有度、等级、基础属性、词条数量和分解产物。
- 随机词条控制属性、数值区间和权重。
- 配方控制蓝图碎片阈值、货币和材料消耗。

### 限时首领

- 首领绑定地图、区域和怪物外观。
- `schedule_anchor` 是周期锚点，`spawn_interval_minutes` 是每隔多久出现，`active_duration_minutes` 是每次持续多久。
- 后台可配置推荐等级、共享生命、攻防、冷却、单窗口挑战次数、最低贡献和成功/超时奖励池。
- 贡献档位按个人累计伤害追加奖励，不提供强制越过配置校验的入口。

### 活动

- 基础信息：活动键、名称、区域说明、开始/结束时间和启用状态。
- 进度来源：全部区域远征，或明确选择若干区域键。
- 故事选项：2–5 个，每个具有稳定键、显示名称、效果类型和百分比；群内唯一领先选项生效，平票时无加成。
- 里程碑：玩家累计活动进度达到数值时发放一个或多个物品，结算具备幂等保护。

## 运营修改顺序

建议依次创建物品与图片、装备和词条、奖励池、怪物和技能、大地图与区域、遭遇与目标、区域远征、限时首领，最后再创建引用这些区域的活动。保存冒险世界时服务端会完整检查引用关系；切换配置方案时还会检查现有玩家宠物、背包、装备、进行中探索、战斗、远征、首领和活动引用，发现缺失键会阻止切换且不修改数据库。
