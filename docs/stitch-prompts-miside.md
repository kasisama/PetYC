# QQPET Admin × 米塔 MiSide — Stitch 提示词全集

> 用于 Google Stitch 生成管理后台 UI。  
> 功能范围以仓库根目录 `STITCH_UI_SPEC.md` 为准；本文只提供可复制粘贴的提示词。

## 使用流程

1. **先发「第 0 条」**，定 Design System 与全局壳。  
2. 之后每一页：先贴 **「每页固定前缀」**，再贴对应页面提示词。  
3. **一页一图**，不要多业务页挤一张。  
4. 默认主题：**米塔的家 · 日间**；多主题验收用 P21 / P22。

---

## 每页固定前缀

每发新页面时，把下面整段放在页面提示词**最前面**：

```text
延续第 0 轮已确定的 QQPET Admin × 米塔 MiSide Design System 与全局 Layout（侧栏+顶栏）。
仅绘制本页主内容区（或本页完整屏），风格必须一致：粉系公寓运营台，中文，桌面 1440 宽优先。
一页一图，不要把多个业务页挤在一张图里。
主题默认：「米塔的家·日间」。
```

### 跑偏时补救句

- 变成通用蓝紫 Admin 时补：

```text
Pull back to MiSide cozy pink apartment ops UI, not generic SaaS blue.
```

- 太幼稚时补：

More premium adult anime apartment, less kids app stickers.

## 第 0 条 · 第一次交流（打地基 · 统一主体基调）

```text
你是 UI 设计师。我们要为「QQPET Admin」设计一整套 Web 运营管理后台界面。

【产品】
- QQ 群宠物养成机器人的服主/运营后台
- 中文界面，桌面优先，兼顾平板与手机
- 用途：看数据、管玩家宠物、调背包、开关 QQ 群、发补偿广播、改游戏配置、热重载、改密码
- 气质一句话：在「欢迎回来，玩家」式的温馨粉系公寓里，放一套认真干活的运营控制台

【视觉总方向 · 米塔 MiSide 风格灵感】
- 关键词：温馨公寓 / 客厅感 / 柔粉玫红 / 奶油白 / 圆角软卡片 / 轻阴影 / 精致二次元点缀 / 略带「太完美所以有点不对劲」的精致感
- 要：清晰表格与表单、中等数据密度、长时间可运营
- 不要：通用蓝紫 Admin 模板、赛博霓虹终端、幼儿贴纸风、血腥 jump-scare、全屏故障动画、为装饰牺牲可读性
- 插画：原创「米塔气质」粉发少女剪影、心形、蝴蝶结、小房间物件即可；不要依赖官方版权立绘；装饰绝不能挡住文字和数据

【三套主题 · 同一信息架构与组件，只换皮肤】
A. 米塔的家·日间（默认）：背景 #FFF8F5 / #FCEEF2，卡片白，主色 #E85A8C~#F47BA8，正文 #3A2A32
B. 米塔的家·夜间：背景 #1A1218，卡片 #2C2028，主色 #FF7AAD，正文 #F5E6EC，暖粉台灯光感
C. 别的米塔（特色）：冷紫黑 #140F18，冷玫 #D63A6A，危险区可用细裂纹/低饱和血红点缀，克制不安，禁止全屏闪烁

【组件规范】
- 圆角：卡片 12–16px，按钮 10–12px，输入 8–10px
- 侧栏像门廊墙面：选中粉底条 + 小心形标记（小、不抢戏）
- 顶栏：主题切换、热重载、当前账号、退出
- 语义色：主粉 / 成功柔青绿 / 警告奶油琥珀 / 危险深红 / 信息雾紫；状态不只靠颜色
- 字体：清晰中文无衬线；数据可用等宽数字；禁止花体正文

【全局壳信息架构（固定，后续所有页必须一致）】
左侧导航：
1. 数据总览
2. 玩家与宠物
3. 运营工具（群组开关、补偿发放）
4. 配置中心（系统参数 / 指令 / 签到 / 打工 / 商店 / 道具 / 宠物种类 / 菜单 / 图片映射）
5. 系统设置（改密、热重载说明、出厂重置危险区）

顶栏固定：Logo「QQPET Admin」+ 主题切换 + 热重载 + 账号菜单

【本轮任务 · 只打地基，不画业务全量细节】
请先输出以下内容（可用标注说明，不必一次画完全部业务页）：
1）Design System 色板、按钮/输入/卡片/表格/标签/弹窗样式示意（日间主题为主）
2）全局 Layout 线框：侧栏 + 顶栏 + 内容区
3）登录页氛围示意（公寓门廊粉雾 + 居中登录卡）
4）用极简占位说明三主题如何换色

【硬性约束】
- 所有文案简体中文
- 不要发明后端没有的功能（如收入趋势、在线人数）
- 后续页面将逐页生成，本轮只统一基调与壳

请先生成：日间主题下的「Design System + 全局 Layout」高保真界面图。
```

## P1 · 登录页

```text
【页面】登录页（无侧栏）

【布局】
- 全屏：柔和公寓门廊/客厅粉雾背景，极淡窗光
- 居中白色圆角登录卡片，轻粉描边与软阴影
- 品牌：主标题「QQPET Admin」，副标题「宠物运营控制台」
- 装饰文案（小字，不抢戏）：「今天也要认真照看大家的宠物哦」

【表单】
- 管理员账号（输入框）
- 管理员密码（输入框）
- 「记住我」复选框（默认未勾选）
- 主按钮「登录」（米塔粉）
- 展示一种错误态示意：字段旁或卡片内提示「账号或密码错误」

【要求】
- 表单对比度高、可点击区域清晰
- 背景插画不遮挡输入
- 米塔风格但专业，不幼儿化
```

- 好感 Top10

【禁止】
- 收入趋势、在线人数、同比增长率等后端没有的数据

## P6 · 删除宠物 · 二次确认弹窗

```text
【组件/弹窗】删除宠物存档确认

【必须展示】
- 宠物昵称、玩家QQ、群号、宠物ID

【文案】
- 标题明确「删除宠物存档」
- 说明不可恢复
- 主危险按钮文案必须是「删除宠物存档」，不能只写「确定」
- 次按钮「取消」

【视觉】
- 略不安的米塔气质（严肃/裂纹细边），仍克制，不血腥
```

## P9 · 补偿发放与群广播

```text
【页面】运营工具 · 补偿发放

【表单分区】
1. 目标：群号（0=所有群）；玩家QQ列表（空=群内全部宠物玩家；支持多个）
2. 奖励：货币（可正可负）；物品（提示格式 饼干*5#抽奖券*10）
3. 广播：多行文案；变量提示 [奖励玩家][奖励货币][奖励物品][换行]；可勾选「只发奖励不广播」

【右侧或下方】
- 实时广播预览区
- 发放摘要（目标群/玩家/货币/物品）

【提交】
- 主按钮「发放」→ 需二次确认弹窗（批量写入警告）
```

## P19 · 系统设置

```text
【页面】系统设置

【区块1 账号安全】
- 修改密码：当前密码 / 新密码 / 确认新密码
- 规则提示：至少6字符；成功后全会话失效需重登

【区块2 配置生效说明】
- 卡片说明：「保存」只写数据库；「热重载」才让机器人内存生效

【区块3 危险区 · 恢复出厂】
- 独立红色/裂纹边框区域
- 文案：将覆盖全部自定义配置，不可逆
- 按钮「恢复出厂配置」→ 强二次确认
- 与温馨主界面形成反差（可偏「别的米塔」气质）
```
