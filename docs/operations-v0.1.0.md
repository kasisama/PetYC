# 自然遗迹调查 · 运营说明 v0.1.0

默认配置版本：`config/defaults/config_v0.1.0.json`（schema 2 / app `0.1.0`）。
题材：原创「自然遗迹调查」。没有第三方 IP。首发允许立绘字段为空，但不得引用已删除图片。

## 1. 世界观和原创命名规范

玩家加入调查队，在三张永久地图里记录生态、修复观测设施，并与五条本地谱系共同成长。

命名只允许使用稳定英文键 + 原创中文名：

- 货币键：`primary_coin`（星砂）、`journey_badge`（调查徽章）、`season_token`（遗迹季印）
- 物品键：如 `field_ration`、`dawn_core`、`season_memento`
- 宠物键：`{family}_base / _evolved / _awaken_a / _awaken_b`
- 禁止再使用：伊布、呱呱、诺诺、菀菀、蔓蔓、雷诺、神树、咔币，以及旧冒险背包/钱包别名

调参时改 `tools/generate_v010.go` 后重新生成 JSON，不要在生产库上手改中文名当主键。

## 2. 玩家循环

### 日循环（10–20 分钟）

签到 → 喂养/送礼 → 短时学习、锻炼或打工 → 探索一个区域 → 视情况领取远征或首领窗口 → 领取里程碑。

### 周循环

- 7 日签到轮换
- 调查商店日/周限购刷新
- 装备更换检查（前期 3–5 天，中期 7–10 天）
- 群共建进度与投票

### 70 天赛季循环

第 1–14 天栖光原野；第 10–35 天潮痕遗址；第 30–70 天雾冠深林。三个首领窗口约在第 10 / 31 / 56 天。赛季商店按 `limit_type=season` 累计限购。

## 5. 货币与材料矩阵

| 资源 | 来源 | 消耗 | 重置 |
| --- | --- | --- | --- |
| 星砂 `primary_coin` | 签到、打工、常规奖励 | 常规商店、改名、治疗 | 不重置 |
| 调查徽章 `journey_badge` | 区域掉落（currency） | 永久调查商店 | 跨季保留 |
| 遗迹季印 `season_token` | 奖励轨货币档 | 赛季商店 `limit_type=season` | 赛季重置清零 |
| 材料/进化核 | 掉落、首领、里程碑 | 制造、进化、兑换 | 不重置 |
| 首季纪念叶 `season_memento` | 赛季商店 | 收藏 | 物品，不是货币 |

`season_token` 只能出现在 `currencies`，不能再作为普通物品。分解返还必须低于制造投入，禁止分解—制造套利。

标准活跃目标：日收入 250–350 星砂，日消耗 180–280。首发不卖战力、不开装备交易。首领奖励按参与门槛发放，不按伤害排名垄断成长资源。

## 6. 装备获取、更换、制造、分解

- 约 30 件模板、6 个词条池、约 30 条词条、12 个核心配方。
- 前期更换 3–5 天，中期 7–10 天，后期约 14 天。
- 制造消耗蓝图碎片 + 星砂 + 材料；分解只返还部分 `soft_clay`。
- 装备绑定账号，穿在具体宠物槽位上。

## 7. 群共建和首领公平分配

三名阶段首领：逐日原角王、深潮观测体、千年雾冠主。共享生命值，奖励按参与和共建门槛发放，不按伤害排行垄断核心材料。群共建消耗共建标识，投票仅影响当前赛季加成。

## 8. 赛季重置与永久保留

后台：`POST /api/admin/seasons/:event_key/reset`
确认文案：`重置赛季:<event_key>`，必须填写操作原因并写入审计。

清除：指定活动进度、发放记录、奖励领取、赛季投票、全部账号 `season_token`（负向账本原因 `season_reset`）。
保留：宠物、图鉴、装备、蓝图、冒险等级、地图进度、星砂、调查徽章。

空库首次加载会把 70 天活动与三个首领窗口锚定到部署当天。

## 9. 调参、告警、紧急止损

1. 改 `tools/generate_v010.go`。
2. `go run ./tools/generate_v010.go`
3. `go test ./config -run TestOfficialSnapshotMeetsLaunchReadiness -count=1`
4. `go run ./tools/simulate_season.go`
5. `python tools/generate_workbook.py`
6. 仅在验收通过后执行 `go run ./tools/rebuild_sqlite.go pet_game.db`

告警阈值建议：

- 标准日净流入连续 3 天高于 220 或低于 20
- 单一谱系战力比超过 1.25
- 赛季商店售罄率低于 10% 或季印沉淀超过标准日产 20 倍
- 首领参与率低于 30%

紧急止损：

- 停用对应 `live_events.active` 或商店 `enabled`
- 不要在运行库上反复 `RebuildOfficialDefaults`
- 赛季经济事故用赛季重置，不要清玩家永久存档

开放第 2 只宠物前：

- 把两个配置调到 2
- 后台玩家详情确认多宠列表与当前宠物切换
- 回归：活动/远征/钓鱼/探索切宠后仍向原宠物结算
- 回归：装备槽 `equipped_pet_id+slot` 唯一
- 确认聊天菜单文案不再写死「只能有一只」
